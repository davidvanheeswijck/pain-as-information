# predictions

Predictions registered against published data that the programme has not yet
read (PROGRAMME.md, "What would count as progress"). Each prediction has its
own folder. Its `REGISTRATION.md` states the claim, the scoring rule, the
unscorable conditions and the prior exposure, and it is committed and merged to
`main` before anyone reads the source. A different agent then reads the source
and writes `RESULT.md` beside it. A registration is not edited after the merge;
amendments are appended and say why. Nothing here is advice about any person's
care (ETHICS.md §3).
